## Scene concept

An appearance panel for a FICTIONAL org's theme: the scene root is the scope root, every `--sx-*`
custom property on it is generated from one authority (`tokens.ts`, `motionLadder.ts`), and a
repository preview card at the top references role names and never a theme, density or scale. Six
regions each rebind part of that root (theme with a three-state preference, density, text scale) or
gate it (the admission desk, the parity gate, the enforcement gate), so a viewer can use it as a
settings surface for a minute while the rail names the technique behind each control. Fixtures are
seeded; the fictional codebase the enforcement gate scans is sized by the volume knob.

## Techniques (rail order = golden path order)

### token-taxonomy
- use_when matched: "deciding whether a candidate token earns its name"
- mechanism to show: two layers rendered side by side (raw slate ramp, then roles with a one-sentence
  definition and both theme bindings); `judgeName()` refuses value-in-name and address-in-name
  candidates before the grammar; three toggles are the three admission tests; the verdict defaults to
  "use the nearest role".
- region: `TaxonomyPanel.tsx`
- Ascent evidence: `src/app/globals.css` `@theme` block (roles by intent with the drift each replaced
  recorded beside it) and `@utility type-*` recipes (grep: `rg "@theme|@utility type-" src/app/globals.css`)
- deviation: only color and type have role layers; radius, spacing, elevation are raw utilities and
  text colour is the palette primitive consumed directly (`text-slate-400`, prescribed by BRAND.md:51).
- applications read: react--token-enforcement (the byte-identical token, the deny-list certifying
  `text-md`); nothing cited as Ascent's.

### theme-architecture
- use_when matched: "role resolves to nothing in one theme state"
- mechanism to show: `resolveTheme(pref, platform)`; `data-theme` + generated bindings on the scene
  root; a completeness matrix from `completeness()` with contrast recomputed from the bindings;
  "drop foreground-muted from light" omits one property so the preview's muted line inherits the
  foreground in light; a nested pane bound to the opposite theme.
- region: `ThemePanel.tsx` (state lifted to `Scene.tsx`)
- Ascent evidence: `src/lib/ui.ts` `readableTextOn()` / `heatCell()` compute on-colours by WCAG
  contrast (`rgbOf`, `relLuminance`, reused by the scene) (grep: `rg "readableTextOn|relLuminance" src/lib/ui.ts`)
- deviation: one theme only; `html { color-scheme: dark }` (globals.css:176), no `data-theme` in src
  (grep: `rg "data-theme|prefers-color-scheme" src` -> 0 hits), no light binding set, no system state.
- applications read: react--theme-architecture (stamp on the root, default theme = bare `:root`, the
  0.01ms reduce collapse, `RETIRED_THEME_FALLBACKS`, seed-stored derivation, advisory derived-theme
  gate); nothing cited as Ascent's.

### cross-language-token-parity
- use_when matched: "choosing between generated mirrors and runtime readback"
- mechanism to show: strategy 1 (the style copy generated by `scopeVars()`; the chart reads
  `DENSITY[density]["row-h"]` for its height) beside strategy 3 (`parityCheck()` over a hand-authored
  legacy mirror: missing member, unequal value, phantom; zero members on either side reports a broken
  instrument, never parity).
- region: `ParityPanel.tsx`; the generated half is visible in `Preview.tsx` (`data-row-h`)
- Ascent evidence: `src/components/ui/format.ts` `DIRECTION_TONE` paired with `--color-tone-*` by a
  "Change BOTH together" comment; `src/lib/site.ts` `BRAND_INK` paired with `--color-ink` the same way
  (grep: `rg "BRAND_INK|DIRECTION_TONE" src`)
- deviation: strategy 4, hand-sync with a comment; no test compares either against globals.css
  (grep: `rg "080d1a|84cc16" src --glob "*.test.*"` finds value assertions, no CSS parse); and
  `src/lib/og/og-brand.tsx` exports a second `BRAND_INK` with a different value (#04070e).
- applications read: node--cross-language-token-parity (fan-out not chain, path as identity,
  byte-stable generated output so a stale generation is a diff, no cross-platform set comparison);
  nothing cited as Ascent's.

### token-enforcement
- use_when matched: "deciding whether a rule should warn or fail the build"
- mechanism to show: `scan()` over `codebaseFor(volume)` with ban + pointer per finding; severity
  picker warn / error / ratchet through `verdict()`; "inline a raw value" and "suppress one inline";
  `suppressionPosture()` (policy / watch / dialect).
- region: `EnforcementPanel.tsx`
- Ascent evidence: `src/components/ui/chip.ts` records the `success` token expanding byte-identically
  to `emerald-500/300` (grep: `rg "byte-identical" src`)
- deviation: no raw-value rule; `eslint.config.mjs` has one error-level gate with a do-not-add
  ratchet list for the `@/lib/db/client` import boundary, not for tokens; 95 tsx files carry hex
  literals (grep: `rg -l "#[0-9a-f]{6}" src --glob "*.tsx"`), 7 carry raw `text-xs`/`text-sm`.
- applications read: react--token-enforcement (warn-level = nothing enforced by construction,
  94-99% vs single-digit adoption, deny-list certifying `text-md`, 143-file migration for one recipe,
  the brightness-filter compensation dialect); nothing cited as Ascent's.

### motion-tokens
- use_when matched: "picking which duration step a change belongs to"
- mechanism to show: `DURATION_MS` ladder + `EASING` roles + `STEP_USE`; a "which step?" picker; a
  chip transitioning on `var(--sx-duration-<step>) var(--sx-ease-move)`; `ladderFor(reduced)` rebinds
  travel steps to a 1ms epsilon at the root, keeps `instant`, flattens `expressive`.
- region: `MotionPanel.tsx`; the rebinding is stamped by `Scene.tsx` via `motionVars()`
- Ascent evidence: `src/app/globals.css` `@media (prefers-reduced-motion: reduce)` block (line 829) with
  "Never add a prefers-reduced-motion check at a call site" (grep: `rg "prefers-reduced-motion" src`)
- deviation: no duration ladder (`0.5s ease-out`, `0.9s`, `360ms cubic-bezier(...)` literals per
  utility); the reduce block sets `animation: none` (exact zero), only `.reveal-quiet` uses 1ms.
- applications read: react--theme-architecture (0.01ms not 0); nothing cited as Ascent's.

### density-and-scale-axes
- use_when matched: "scaled text clips in fixed-size containers"
- mechanism to show: `DENSITY` (space roles) and `TYPE_BASE_PX * scale` (type roles) as two more
  rebindings at the root; `AXIS_OWNERSHIP` rendered as the disjointness matrix; a 44px box vs an
  em-sized box with the clip verdict computed from the authority.
- region: `AxesPanel.tsx` (state lifted to `Scene.tsx`)
- Ascent evidence: `src/app/globals.css` `@theme` `--text-*` rebase (+1px across the ramp, every
  consumer unaware) (grep: `rg "ONE PIXEL over the framework default" src/app/globals.css`)
- deviation: no user axis exists (no density, no runtime text scale, no brightness, no `data-*`
  stamp); the rebase is an authoring-time constant.
- applications read: react--theme-architecture (`data-text-scale`, `data-density` driving
  `--density-pad/-gap`, the whole-document brightness filter clamping foreground tints); nothing cited
  as Ascent's.

## Out of the read

- The migration section of the golden path (a token change sweeps what it referenced AND what it
  overrode) is prose about process; no region attempts it.
- Startup ordering (flash of the wrong theme) needs a real boot; the scene notes the three-state model
  only.
- Derived themes from a seed (derivation-names-recomputation) are a generator; out of scope for a
  fixture scene, mentioned in the theme drawer only through the computed on-colour clause.
- The scene uses no framer-motion: CSS transitions on token variables are the subject.
